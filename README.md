# Lumaicons

App icons for the macOS-in-web desktop.

## Usage (jsDelivr Fastly)

After you push this folder to GitHub as repo `Lumaicons` under your user:

```
https://fastly.jsdelivr.net/gh/<YOUR_USER>/Lumaicons@main/Finder.png
https://fastly.jsdelivr.net/gh/<YOUR_USER>/Lumaicons@main/Twitch.png
```

Example in HTML:

```html
<img src="https://fastly.jsdelivr.net/gh/mathissofun137/Lumaicons@main/Safari.png" alt="Safari">
```
